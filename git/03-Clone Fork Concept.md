### Fork

- Forking from GitHub gives 2 features:
    - ✅ ability to suggest changes → Pull Request
    - ✅ ability to sync with original repo (upstream) ==> (fetch upstream, as we are the downstream )

👉 Important concept:

- **Upstream** = original repo
- **Origin** = your fork
